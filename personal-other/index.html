FOCUSFLOW

ADHD Executive Function Support App

FocusFlow is a mobile task-support prototype designed for people with ADHD traits. It combines flexible task planning, time visualization, and gamified feedback within one mobile interface.

TYPE Mobile App Front-End Prototype
ROLE Product Concept, UX/UI Design and Front-End Development
TOOLS React Native, Expo and Visual Studio Code
YEAR 2026

Two interface modes support different levels of energy, attention, and task pressure.

FLEXIBLE TASK PLANNING

The task system provides three reminder structures for different schedules and attention states.

Exact Time

A fixed reminder for tasks with a clear schedule.

02

Flexible Exact Time

A reminder that can move within a short period around the selected time.

Random Time Range

A reminder sent at a random point within a selected period.
